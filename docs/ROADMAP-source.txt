const AGENTS_MD = `# AGENTS.md (port personal de Project Zomboid al navegador)

## Reglas duras
- Nunca agregues al repo archivos del juego: ni .jar, .class, .so, media/, .bank, mapas, ni código decompilado o desensamblado.
- Los archivos del juego se leen de PZ_HOME (mi copia fija) en build time o desde el dev server local.
- El repo es privado. El dev server escucha solo en 127.0.0.1.
- Las nativas ausentes lanzan una excepción con su nombre JNI. Nunca un stub que devuelve éxito.
- No cambies la lógica del juego: solo plataforma (archivos, gráficos, input, audio, nativas).

## Stack
- TeaVM 0.16.0, backend WebAssembly GC. JDK 25. Maven. Node 24. Chrome estable.
- Emscripten solo para Bullet (módulo wasm32 separado).
- Builds: scripts/build.sh (MAVEN_OPTS=-Xmx20g).

## Cómo trabajar
- Un cambio chico por tarea, con un test que corra en la JVM y en Chrome (Playwright).
- Ante la duda, compará contra el juego real en mi PC (logs, grabaciones de tools/jnitrace, capturas de RenderDoc).
- Documentá cada decisión en docs/decisions.md (una línea por decisión).`;
